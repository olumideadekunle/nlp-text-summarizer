# NLP Text Summarizer

Summarizes long text using two approaches — **Extractive** (TF-IDF sentence scoring) and **Abstractive** (Facebook BART model). Comes with a Streamlit web app, a CLI tool, and a ROUGE evaluation script.

## Setup

```bash
pip install -r requirements.txt
```

## Run

**Web app (Streamlit):**
```bash
streamlit run app.py
```
Then open `http://localhost:8501` in your browser.

**Command line (no Streamlit needed):**
```bash
# Built-in sample text
python run_cli.py

# Your own text
python run_cli.py --text "Your long text here..." --mode both

# From a .txt file
python run_cli.py --file input.txt --mode extractive

# Abstractive only
python run_cli.py --text "Your text..." --mode abstractive
```

**Evaluate with ROUGE scores:**
```bash
python evaluate.py
```

## How It Works

| Method | Approach | Model |
|--------|----------|-------|
| Extractive | Scores sentences using TF-IDF, picks top N | NLTK + scikit-learn |
| Abstractive | Generates a new summary from scratch | `facebook/bart-large-cnn` |

> First run of abstractive mode downloads BART (~1.6 GB) and caches it automatically.

## Output Files

| File | Description |
|------|-------------|
| `output.csv` | Summaries saved after each run |
| `evaluation_results.csv` | ROUGE-1, ROUGE-2, ROUGE-L scores per method |
| `sample_output.csv` | Preview of expected results |
